# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities, exposed
credentials, or privacy-sensitive findings. Use GitHub private vulnerability
reporting if it is enabled for this repository, or contact the maintainer
through the contact method listed on the repository profile.

Do not attach real personal, school, customer, employer, or production
documents, unredacted logs, or live `*_redacted.md` output to a report.

## Scope

This toolkit is designed for local processing with Apple on-device models
plus Private Cloud Compute. It does not use third-party model hosts, and
it does not guarantee complete redaction, anonymisation, legal compliance,
or protection from user or environment misconfiguration. Always review
output manually before sharing, uploading, or relying on it.
