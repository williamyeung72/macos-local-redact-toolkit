# Contributing

Contributions are welcome.

## Before opening a pull request

- Do not include real personal, school, customer, employer, or production data.
- Do not commit API keys, tokens, passwords, certificates, logs, or local output.
- Use synthetic sample documents only.
- Keep Apple Silicon/macOS compatibility in mind.
- Test Finder Quick Actions and CLI paths where relevant.
- Update README or troubleshooting notes when behaviour changes.

## Reporting bugs

Please include:

- macOS version
- Apple Silicon or Intel Mac
- Python and Ollama versions
- input file type
- selected PDF mode
- relevant sanitized log excerpt
- expected and actual behaviour

Do not include private documents or unredacted sensitive content.
